BUG P11: Dead-end curl-back puts the picked waypoint near the ship

Session: ai_nav_2026-07-25T11-01-09   Tick: 391   State: lat 8.64, lon 32.85 (Sudd marshland approach), hdg 122° ESE

BUG P10: Bank trace walks the wrong direction from the port projection
