# Combat System

Loaded from CLAUDE.md on demand.

**Initiating combat**: declare on adjacent fleet → opponent chooses
Combat / Retreat / Surrender / Parley.

**Map**: hexagonal tiles, turn order by ship Mobility.  Win = sink all
enemy ships.

**Actions per turn**: Artillery, Melee, Ram, Duel, Support Skills
(Repair / Medicine / Tool), Mate Combat Skills.  Flagship uses Admiral's
Orders without consuming a turn.

## Combat modes
- **Manual** — full player control.
- **Fast Combat** — simplified animations (limited uses; Beginner Benefits
  provide free uses).
- **Auto Combat** — automated but tends toward head-on attacks; configure
  Mate Skill / Admiral's Order usage in Settings.
- **Offline Combat** — battles happen during offline sailing; configure
  via Menu → Company Overview → Aide.

## Repel Support
Instant win when fleet Combat Power ≥ 1.3× enemy:
- Standard: 5 Repel Supports consumed
- Area occupation: 4; Monopoly: 3
- Free Repels (max 300) from completing all Daily Tasks; paid unlimited
  from shop
- Does NOT work against powerful opponents, event fleets, or quest targets

## Naval Protection / Ceasefire
- Included in Beginner Benefits.  After benefits end, buy Ceasefire
  Agreements at Shop → Product Tab (or event rewards).
- Toggle at upper-right icon; enabling requires entering a city.
